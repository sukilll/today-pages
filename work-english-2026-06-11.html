Code Review & Technical Feedback
Word of the Day
caveat /ˈkæv.i.æt/
注意事项；警告；附加条件
A caveat is a warning or qualification that points out a potential problem, limitation, or exception. In code reviews and technical discussions, it signals "this works, but watch out for..."
This solution works well — one caveat: it assumes the input array is always sorted.
I'll approve this PR, but I want to add a caveat that we should revisit the caching logic before the next release.
Sentence Patterns
"Just a nit, but ___."
代码评审 · PR 反馈
小问题，不影响大局，但值得一提
Just a nit, but the variable name data2 could be more descriptive — maybe filteredResults?
Just a nit, but this comment is outdated — the function signature changed in the last refactor.
"This might be a bit brittle when ___."
代码评审 · 稳定性讨论
在某种情况下可能不够稳定/健壮
This might be a bit brittle when the API returns an empty array — we should add a null check.
This regex might be a bit brittle when users enter non-ASCII characters; worth adding a test case.
"This is a trade-off between ___ and ___."
技术方案讨论 · 架构评审
这是…和…之间的权衡
This is a trade-off between performance and readability — the optimized version is faster but harder to maintain.
This is a trade-off between flexibility and simplicity; I'd lean toward simplicity for now and refactor later.
Mini Scenario
You're reviewing a teammate's PR for a new data-fetching module. You leave a comment: "Caveat: this approach works great for small datasets, but this might be a bit brittle when we scale to thousands of records — pagination isn't handled yet. Just a nit, but the helper function name could be clearer too. Overall this is a trade-off between shipping fast and building for scale — happy to discuss which direction makes sense for this sprint."
Quick Tip
💡
In English code reviews, softening your feedback with phrases like "just a nit" or "might be brittle" makes criticism feel collaborative rather than confrontational. This is especially important in async reviews where tone is hard to read. Saying "LGTM with one caveat" is a polite way to approve while flagging a concern — it shows you trust your teammate's judgment while still being thorough.
