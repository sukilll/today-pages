Word of the Day
brittle /ˈbrɪt.əl/
adj. 脆弱的；易崩溃的（指代码或设计）
Code that works under specific conditions but breaks easily when things change. A brittle implementation is technically correct but fragile — one small change elsewhere can make it fail.
This regex is brittle — it'll break the moment someone adds a new URL format.
The test suite is too brittle; it fails on every minor refactor even when the behavior is correct.
Sentence Patterns
"This feels a bit brittle because ___."
代码审查 · 设计讨论
这个实现感觉有点脆弱，因为……
This feels a bit brittle because it hardcodes the timeout value — what if the server is slow?
This feels a bit brittle because it relies on the order of keys in a JSON object, which isn't guaranteed.
"Is there a more robust way to handle ___?"
代码审查 · 技术讨论
有没有更稳健的方式来处理……？
Is there a more robust way to handle the case where the API returns an empty array?
Is there a more robust way to handle timezone differences here instead of assuming UTC?
"This works for now, but it might break when ___."
代码审查 · 风险提示
现在能跑，但当……的时候可能会出问题
This works for now, but it might break when we scale to multiple regions.
This works for now, but it might break when the user has more than 1000 items in the list.
Mini Scenario
You're reviewing a PR that parses user input with a hardcoded pattern. You leave a comment:

"Hey, brittle concern here — this feels a bit brittle because it assumes the input always starts with a capital letter. Is there a more robust way to handle mixed-case inputs? This works for now, but it might break when we add support for non-English locales."
Quick Tip
💡
When pointing out fragile code in a review, lead with the risk scenario rather than the judgment. Instead of "this is brittle," say "this might break when X happens." It shifts the tone from criticism to collaboration — you're both solving the same problem, not grading each other's work.
