Code Review & Technical Feedback
Word of the Day
verbose /vɜːrˈboʊs/
冗长的；啰嗦的
Using more words or code than necessary to express something. In tech contexts, it often describes code that is overly long-winded when a simpler version would do the same job.
This function is a bit verbose — we could replace those 20 lines with a single list comprehension.
The error message is too verbose for end users; let's show a cleaner summary instead.
Sentence Patterns
"Could we refactor this to ___?"
代码评审 · PR 评论
能否重构成……？（提出改进建议，语气委婉）
Could we refactor this to use a helper function so it's easier to test?
Could we refactor this to avoid the nested loops — it's getting hard to follow?
"Have you considered ___?"
代码评审 · 技术讨论
你有没有考虑过……？（引导对方思考替代方案）
Have you considered using a map here instead of a for-loop? It'd be more readable.
Have you considered what happens when the list is empty? That edge case might cause a crash.
"This might be a bit brittle when ___."
代码评审 · 稳定性反馈
在某种情况下这段代码可能不够稳定
This might be a bit brittle when the API returns a null value — worth adding a guard.
This might be a bit brittle when we scale to thousands of records; let's add a limit.
Mini Scenario
You're reviewing a teammate's PR and want to leave helpful, constructive comments.

"Hey, overall this looks good! One thing — the config parser is a little verbose; there are about 30 lines that could be condensed. Could we refactor this to use a dictionary comprehension instead? Also, have you considered what happens when a required key is missing from the config file? This might be a bit brittle when someone runs this in a fresh environment without all the defaults set."
Quick Tip
💡
In English code reviews, framing feedback as a question ("Could we…?", "Have you considered…?") is much softer than a direct command ("Change this to…"). It signals collaboration rather than criticism — the reviewer is thinking alongside the author, not judging them. This is especially important in async PR comments where tone is easy to misread. When you do want to be direct, add a softener like "just a nit" or "minor thing" to signal the issue isn't blocking.
